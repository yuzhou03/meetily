## 二、Pro版权益
### 已解锁的Pro核心功能
- 实时录制与转录
- 支持云端AI提供商（Claude、GPT-4、Groq、OpenRouter）
- 支持自定义OpenAI兼容服务器
- 自动检测会议

### Pro版功能详细说明
1. **录制与转录**：支持实时会议录制，集成Whisper AI转录、说话人检测及专业音频混音
2. **云端AI提供商**：可调用Claude、GPT-4、Groq、OpenRouter生成高级AI会议摘要
3. **自定义OpenAI服务器**：支持连接自建的OpenAI兼容API端点（如vLLM、远程Ollama、Text Generation WebUI等）
4. **自动检测会议**：自动识别会议应用调用麦克风的行为，并推送录制提醒

## 三、免费版（无Pro）权益
- 查看所有会议的录制文件和转录文本
- 编辑、更新会议摘要
- 使用本地部署的Ollama模型生成AI摘要
