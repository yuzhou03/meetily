# Windows平台智能会议纪要Agent调研报告

## 一、报告概述

### 1\.1 调研背景

随着远程办公和混合办公模式的普及，智能会议纪要工具已成为企业数字化办公的核心基础设施。本报告针对 Windows 10/11 平台，调研业界主流的会议纪要 AI Agent 产品，重点关注**Windows 平台兼容性**、**本地部署能力**、**数据安全性**等核心指标，为企业选型提供决策依据。

### 1\.2 调研范围

本次调研覆盖**11 款**业界主流产品，包括：

- **国际产品**：\[Otter\.ai\]\(Otter\.ai\)、\[Fireflies\.ai\]\(Fireflies\.ai\)、Fathom、Meetily、tl;dv、Krisp、Notta

- **国内产品**：讯飞听见、听脑 AI、通义听悟、钉钉闪记

### 1\.3 评估维度

|评估维度|说明|
|---|---|
|Windows 兼容性|是否提供原生 Windows 客户端、系统版本支持|
|本地部署能力|是否支持私有化部署、本地处理、离线运行|
|核心功能|音频采集、转写准确率、说话人分离、纪要生成|
|多模态支持|屏幕截图、白板照片、PPT 提取等图文处理能力|
|费用成本|免费额度、订阅价格、企业版定价|
|数据安全|加密方式、合规认证、数据主权|
|集成生态|与主流会议软件、办公系统的集成能力|

## 二、产品详细调研

### 2\.1 国际产品系列

#### 1\. Meetily（开源本地部署首选）

**核心定位**：100% 本地处理的开源会议纪要助手，MIT 许可

**关键特性**：

- ✅ **Windows 原生支持**：提供 x64\-setup\.exe 安装包，支持 Windows 10/11

- ✅ **完全本地部署**：基于 Whisper 模型，音频 / 转写 / 总结全流程本地处理

- ✅ **离线运行**：无需联网，支持断网环境使用

- ✅ **无 Bot 模式**：本地音频采集，无需机器人加入会议

- ✅ **开源免费**：GitHub 11\.6K\+ Stars，MIT 许可证可商用

**技术架构**：

- 前端：Rust \+ Tauri，原生桌面体验

- 后端：Whisper/Parakeet 语音识别 \+ 可选本地 LLM 总结

- 存储：本地 SQLite 数据库，数据完全自主可控

**费用**：完全免费，企业支持服务需定制

**适用场景**：金融、法律、医疗等数据敏感行业，对隐私要求极高的企业

**优缺点**：

|优点|缺点|
|---|---|
|100% 数据本地化，零隐私风险|需一定技术能力配置本地 LLM|
|开源可定制，无供应商锁定|中文方言支持较弱|
|无使用时长限制|UI 交互体验较商业化产品简陋|
|Windows 原生客户端性能优异|企业级功能需自行开发|

## 五、推荐结论与选型建议

### 5\.1 核心选型决策树

```Plain Text
开始选型
    ↓
是否有强制数据本地化要求？
    ├─ 是 → 进入【隐私优先路径】
    │   ├─ 预算充足 + 企业级 → 推荐：听脑AI 私有化部署
    │   ├─ 技术能力强 + 可控性优先 → 推荐：Meetily 开源本地部署
    │   └─ 专业领域 + 中文为主 → 推荐：讯飞听见 私有化部署
    │
    └─ 否 → 进入【功能优先路径】
        ├─ 主要使用中文？
        │   ├─ 是 → 国内产品优先
        │   │   ├─ 钉钉深度用户 → 钉钉闪记
        │   │   ├─ 预算敏感/学生 → 通义听悟
        │   │   └─ 追求最高精度 → 讯飞听见SaaS
        │   │
        │   └─ 否/多语言 → 国际产品优先
        │       ├─ 销售团队 → Fireflies.ai
        │       ├─ 个人/免费 → Fathom
        │       ├─ 英语为主 → Otter.ai
        │       └─ 环境嘈杂 → Krisp
        │
        └─ 是否需要屏幕/白板多模态？
            ├─ 是 → 通义听悟（PPT提取）、讯飞听见
            └─ 否 → 按上述场景选择
```

### 5\.2 分场景具体推荐

#### 🏆 推荐一：数据安全优先型企业

**首选方案：听脑 AI 私有化部署**

- **理由**：国内唯一提供完整私有化且支持完全断网运行的成熟产品

- **替代方案**：讯飞听见私有化部署（专业领域识别更优）

- **技术极客方案**：Meetily 开源本地部署（零成本，需技术配置）

#### 🏆 推荐二：Windows 原生体验优先

**首选方案：讯飞听见 Windows 客户端**

- **理由**：Windows 客户端最成熟，中文识别准确率业界第一

- **降噪需求**：追加 Krisp Pro（驱动级降噪，兼容所有会议软件）

#### 🏆 推荐三：中小企业性价比之选

**首选方案：通义听悟**

- **理由**：每日 10 小时免费额度基本够用，阿里大模型总结质量高

- **钉钉用户**：直接使用钉钉闪记，零额外成本

#### 🏆 推荐四：个人 / 自由职业者

**首选方案：Fathom（免费）\+ Krisp 免费版**

- **理由**：Fathom 无限免费转写，Krisp 每日 60 分钟免费降噪

- **预算充足**：Notta Pro（多语言支持最好）

#### 🏆 推荐五：跨国 / 多语言团队
